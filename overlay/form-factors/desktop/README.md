# Googlebook / ChromeOS / desktop windowing — no module

This form factor adds no module: `/android-forge-add-form-factor desktop` pastes `app-manifest-snippet.xml` into `:app`'s
manifest and installs the `desktop` skill tier. Everything else — tiers, opt-in code paths, QA — is in
[docs/form-factors/desktop.md](../../../docs/form-factors/desktop.md).
