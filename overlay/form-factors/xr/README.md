# Android XR headsets — no module

This form factor adds no module: `/android-forge-add-form-factor xr` pastes `app-manifest-snippet.xml` into `:app`'s
manifest and installs the `xr` skill tier. Everything else — tiers, opt-in code paths, QA — is in
[docs/form-factors/xr.md](../../../docs/form-factors/xr.md).
